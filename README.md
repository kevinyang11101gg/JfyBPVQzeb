# Python旅游景点推荐系统

## 核心功能
- 用户管理
- 景点数据爬取
- 景点信息推荐
- 景点详情浏览
- 景点收藏
- 景点数据可视化分析
- 景点信息管理

## 适用场景
- 旅游爱好者
- 旅游机构
- 地方旅游局
- 旅游规划者

## 技术特点
- 使用 Django 框架构建
- 数据库采用 MySQL
- 前端界面采用 HTML、CSS、JS
- 支持用户登录注册及权限管理
